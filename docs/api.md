## `<compress>`

Zlib, gzip and raw DEFLATE compression and decompression,
ZIP archives, and the CRC-32 and Adler-32 checksums.

Each part is also a module of its own: `<compress/checksum>`,
`<compress/inflate>`, `<compress/deflate>`, `<compress/zlib>`, `<compress/gzip>` and
`<compress/zip>`.


## `<compress/checksum>`

CRC-32 (the gzip and ZIP one) and Adler-32 (the zlib one).

Both come in a one-shot form and an incremental one that takes the value
returned by the previous call, so data can be checked in pieces:

```eskiu
uint32 c = crc32(data, n);
uint32 d = crc32_update(crc32_update(0, data, 10), data + 10, n - 10);   // c == d

```

The incremental forms start from 0 for CRC-32 and 1 for Adler-32, as zlib's
crc32() and adler32() do. CRC-32 reads 8 bytes per step through eight
256-entry tables (slicing-by-8), built on first use; a thread that comes in
while another builds them waits for it.

### CRC32_INIT

```eskiu
const uint32 CRC32_INIT = 0;
```

The value crc32_update starts from for the first piece.

### ADLER32_INIT

```eskiu
const uint32 ADLER32_INIT = 1;
```

The value adler32_update starts from for the first piece.

### crc32_update

```eskiu
uint32 crc32_update(uint32 crc, *uint8 p, uint64 n)
```

Continues a CRC-32 over n more bytes. crc is 0 for the first piece.

### crc32

```eskiu
uint32 crc32(*uint8 p, uint64 n)
```

The CRC-32 (zlib's, as in gzip and zip) of n bytes at p.

### adler32_update

```eskiu
uint32 adler32_update(uint32 adler, *uint8 p, uint64 n)
```

Continues an Adler-32 over n more bytes. adler is 1 for the first piece.
The sums are reduced every 5552 bytes, the most that cannot overflow 32 bits.

### adler32

```eskiu
uint32 adler32(*uint8 p, uint64 n)
```

The Adler-32 (as in zlib streams) of n bytes at p.


## `<compress/deflate>`

Raw DEFLATE compression (RFC 1951).

Levels 0 to 9 as in zlib: 0 stores the data, 1 to 3 take the first match
found along a short hash chain, 4 to 9 search longer chains and defer each
match by one byte to see whether the next position has a longer one (lazy
matching). The window is the full 32 KB.

```eskiu
Bytes comp = deflate_raw(data, n, 6)?;
defer comp.free();

```

The matches are collected into blocks of 16384 symbols. Each block is
written in whichever form is smallest: stored, the fixed Huffman codes, or
codes built from the block's own symbol counts, limited to 15 bits.

### DEFLATE_STORE

```eskiu
const int DEFLATE_STORE = 0;
```

Level 0: the data stored in stored blocks, not compressed.

### DEFLATE_FAST

```eskiu
const int DEFLATE_FAST = 1;
```

Level 1: the fastest compression.

### DEFLATE_DEFAULT

```eskiu
const int DEFLATE_DEFAULT = 6;
```

Level 6: zlib's default trade between speed and size.

### DEFLATE_BEST

```eskiu
const int DEFLATE_BEST = 9;
```

Level 9: the smallest output, slowest.

### deflate_raw_append

```eskiu
Result<int, string> deflate_raw_append(*uint8 src, uint64 len, int level, Bytes* out)
```

Compresses src[0..len) at the given level (clamped to 0..9) and appends the
raw DEFLATE stream to out.

### deflate_raw

```eskiu
Result<Bytes, string> deflate_raw(*uint8 src, uint64 len, int level)
```

Compresses src[0..len) into a new Bytes holding a raw DEFLATE stream.

### deflate_bound

```eskiu
uint64 deflate_bound(uint64 len)
```

An upper bound on the compressed size of len bytes at any level.


## `<compress/gzip>`

The gzip format (RFC 1952), a header, a DEFLATE stream, and the
CRC-32 and size of the data.

```eskiu
Bytes gz = gzip_compress(data, n, 6)?;
GzipOptions o = GzipOptions{level: 9, name: "notes.txt", mtime: 1700000000};
Bytes named = gzip_compress_with(data, n, &o)?;
Bytes back = gzip_decompress(gz.data, (uint64)gz.len)?;

```

Decompression joins every member of a multi-member file (what `cat a.gz
b.gz` makes) and checks each one's CRC-32 and size. Zero bytes after the
last member are ignored, as gzip(1) does; anything else is an error.
gzip_header reads the first member's file name, comment and time.

### GZIP_OS_UNKNOWN

```eskiu
const int GZIP_OS_UNKNOWN = 255;
```

The operating system byte gzip_compress writes in the header: unknown, so the output
does not depend on the machine.

### GzipOptions

```eskiu
struct GzipOptions {
    int level;
    string name;
    string comment;
    uint32 mtime;
}
```

What gzip_compress_with writes into the header: name (or null for none)
and mtime (Unix seconds, 0 for none) are optional.

### GzipHeader

```eskiu
struct GzipHeader {
    String name;
    String comment;
    uint32 mtime;
    int xfl;
    int os;
    bool text;
    uint64 size;
}
```

A member header as read by gzip_header. name and comment are empty when the
header has none; size is the header's length in bytes.

### GzipHeader_free

```eskiu
void GzipHeader_free(GzipHeader* self)
```

Frees the header's name and comment.

### gzip_header

```eskiu
Result<GzipHeader, string> gzip_header(*uint8 src, uint64 len)
```

Reads the header of the first member. Free the result with GzipHeader_free.

### gzip_compress_with

```eskiu
Result<Bytes, string> gzip_compress_with(*uint8 src, uint64 len, GzipOptions* o)
```

Compresses src[0..len) into a single-member gzip file with the given header fields.

### gzip_compress

```eskiu
Result<Bytes, string> gzip_compress(*uint8 src, uint64 len, int level)
```

Compresses src[0..len) into a gzip file with no name and no time.

### gzip_decompress_limit

```eskiu
Result<Bytes, string> gzip_decompress_limit(*uint8 src, uint64 len, uint64 limit)
```

Decompresses every member of a gzip file into a new Bytes of at most limit bytes.

### gzip_decompress

```eskiu
Result<Bytes, string> gzip_decompress(*uint8 src, uint64 len)
```

Decompresses a gzip file into a new Bytes of at most INFLATE_DEFAULT_LIMIT bytes.


## `<compress/inflate>`

Raw DEFLATE decompression (RFC 1951).

Two output forms. inflate_raw grows a Bytes as the data comes, up to a size
limit (1 GB unless given), so a small hostile stream cannot expand into all
of memory. inflate_raw_into writes into a buffer the caller sized, for
formats that state the output size up front, and fails when the data does
not fit:

```eskiu
Bytes out = inflate_raw(src, n)?;
defer out.free();
uint64 got = inflate_raw_into(src, n, dst, cap)?;

```

Every read of the input is bounds checked; reading past the end feeds zero
bits and is reported as a truncated stream. Huffman codes are decoded
through a 9-bit lookup table with a canonical-code fallback for the longer
ones, the scheme used by stb_image and zlib.

### INFLATE_DEFAULT_LIMIT

```eskiu
const uint64 INFLATE_DEFAULT_LIMIT = 1073741824;
```

The most bytes the decompressors produce unless told otherwise (1 GiB): a larger output
is an error, so a small hostile input cannot fill the memory.

### inflate_raw_append

```eskiu
Result<uint64, string> inflate_raw_append(*uint8 src, uint64 len, Bytes* out, uint64 limit)
```

Decodes raw DEFLATE data, appending to out (an initialised or zeroed
Bytes), which may not grow past limit bytes in total. Returns how many input
bytes the stream took, so a caller can find what follows it. On an error out
keeps what was decoded so far.

### inflate_raw_limit

```eskiu
Result<Bytes, string> inflate_raw_limit(*uint8 src, uint64 len, uint64 limit)
```

Decodes raw DEFLATE data into a new Bytes of at most limit bytes.

### inflate_raw

```eskiu
Result<Bytes, string> inflate_raw(*uint8 src, uint64 len)
```

Decodes raw DEFLATE data into a new Bytes of at most INFLATE_DEFAULT_LIMIT bytes.

### inflate_raw_into

```eskiu
Result<uint64, string> inflate_raw_into(*uint8 src, uint64 len, *uint8 dst, uint64 cap)
```

Decodes raw DEFLATE data into dst, which holds cap bytes. Returns the number
of bytes written.


## `<compress/zip>`

Reading and writing ZIP archives (PKWARE APPNOTE), with the
stored and deflate methods and ZIP64 for large archives.

```eskiu
ZipReader r = ZipReader_open("pack.zip")?;
defer r.close();
for (i in 0..r.count()) printf("%s %llu\n", r.entry(i).name.data, r.entry(i).size);
Bytes b = r.read_name("docs/readme.txt")?;
defer b.free();

ZipWriter w = ZipWriter_new();
defer w.free();
w.add_dir("docs");
w.add("docs/readme.txt", (*uint8)text, strlen(text), 6)?;
w.finish_file("out.zip")?;

```

The reader takes the entry list from the central directory and checks each
entry's local header, size and CRC-32 when it is read. An entry is never
inflated past the size the directory states, and an entry stating more than
the reader's limit (INFLATE_DEFAULT_LIMIT unless changed) is refused, so a
small archive cannot expand into all of memory. Encrypted entries, archives
split over several disks and methods other than stored and deflate are
reported as errors. ZipReader_extract_all refuses archives with an absolute
entry name or a ".." component, and writes symbolic links as regular files
holding the link target.

Times are DOS times (2-second steps, 1980 to 2107) read and written as UTC;
when an entry carries the extended timestamp field, its Unix time is used.

### ZIP_STORED

```eskiu
const int ZIP_STORED = 0;
```

An entry stored as it is (compression method 0).

### ZIP_DEFLATED

```eskiu
const int ZIP_DEFLATED = 8;
```

An entry compressed with deflate (compression method 8).

### ZipEntry

```eskiu
struct ZipEntry {
    String name;
    int method;
    int flags;
    uint32 crc;
    uint64 compressed_size;
    uint64 size;
    int64 mtime;
    uint32 external_attrs;
    uint64 offset;
    bool is_dir;
}
```

An entry of the archive from the central directory: its name (directories end in /),
compression method, general-purpose flags, CRC-32, compressed and uncompressed sizes,
modification time (Unix seconds), external attributes (Unix mode in the high 16 bits
when the archive comes from Unix), the offset of its local header and whether it is a
directory.

### ZipReader

```eskiu
struct ZipReader {
    *uint8 data;
    uint64 len;
    bool owned;
    uint64 shift;
    uint64 limit;
    List<ZipEntry> entries;
}
```

An open archive: the bytes (owned when read from a file), the entries, and the most
bytes one entry may decompress to (limit).

### ZipWriter

```eskiu
struct ZipWriter {
    Bytes out;
    List<_ZipCentral> entries;
    int64 mtime;
    bool zip64;
    bool finished;
}
```

A writer collects the archive in memory. mtime (Unix seconds, the time of
ZipWriter_new by default) is stamped on the entries added after it is set;
zip64 set to true writes ZIP64 records even when nothing needs them.

## `<compress/zlib>`

The zlib format (RFC 1950), a DEFLATE stream between a 2-byte
header and an Adler-32 of the data.

```eskiu
Bytes z = zlib_compress(data, n, 6)?;
defer z.free();
Bytes back = zlib_decompress(z.data, (uint64)z.len)?;
defer back.free();

```

Decompression checks the header and the Adler-32 and stops at the end of
the stream; bytes after it are ignored, as zlib's uncompress() does. Streams
that need a preset dictionary are rejected.

### zlib_compress

```eskiu
Result<Bytes, string> zlib_compress(*uint8 src, uint64 len, int level)
```

Compresses src[0..len) into a zlib stream at a level from 0 to 9.

### zlib_decompress_limit

```eskiu
Result<Bytes, string> zlib_decompress_limit(*uint8 src, uint64 len, uint64 limit)
```

Decompresses a zlib stream into a new Bytes of at most limit bytes.

### zlib_decompress

```eskiu
Result<Bytes, string> zlib_decompress(*uint8 src, uint64 len)
```

Decompresses a zlib stream into a new Bytes of at most INFLATE_DEFAULT_LIMIT bytes.

### zlib_decompress_into

```eskiu
Result<uint64, string> zlib_decompress_into(*uint8 src, uint64 len, *uint8 dst, uint64 cap)
```

Decompresses a zlib stream into dst, which holds cap bytes, and returns the
number of bytes written.
